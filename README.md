# TODO Next.js App

This is a Next.js application used for demonstrating the TODO functionality. It is created to practice building web applications with Next.js with other technologies like Tanstack Query, Zustand, Zod, Shadcn UI, and more.

## Features

- Create, Read, Update, and Delete (CRUD) TODO items
- Responsive design with Shadcn UI components
- State management with Zustand
- Data fetching and caching with Tanstack Query
- Form validation with Zod

## Technologies Used

- [Next.js](https://nextjs.org/)
- [Tanstack Query](https://tanstack.com/query/latest)
- [Zod](https://zod.dev/)
- [Shadcn UI](https://shadcn.com/ui)
- [Zustand](https://zustand-demo.pmnd.rs/)
- [MongoDB](https://www.mongodb.com/)
- [Mongoose](https://mongoosejs.com/)
